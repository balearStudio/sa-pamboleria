for rendered visual directions with named typefaces, hex palettes and registry checks.

are decided by Claude Design at the `/ewf:design` stage, from the brief, the photographs and
the reference board — **not here**.

influence the design. It is kept only so the reasoning is not lost. The real deliverables of
this stage are `../board.md` and the written direction in `DESIGN.md`.
